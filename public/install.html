Install R-IIT Bharat Mentors

Add the app to your home screen. Sign in with the same student account you use on the website.

Android

Open this site in Chrome. Tap the three-dot menu, then Add to Home screen and Install.

iPhone and iPad

Open this site in Safari. Tap Share, then Add to Home Screen. Enable Open as Web App if shown, then tap Add.

Practice, booking and payments need an internet connection.
